# Chỉ dẫn cho agent

Đọc và tuân theo [agent.md](agent.md) trước khi làm việc trong repo. Dùng [SYSTEM_DESIGN.md](SYSTEM_DESIGN.md) để hiểu kiến trúc và mục đích các file, thư mục; dùng [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) để chọn phần code tiếp theo. Khi code video, đọc [VIDEO_IMPLEMENTATION_PLAN.md](VIDEO_IMPLEMENTATION_PLAN.md) trước. Các tài liệu có mô tả cấu trúc dự kiến; luôn kiểm tra hiện trạng trên đĩa trước khi sửa.
